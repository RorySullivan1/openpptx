## Gotchas & dead ends
- The Bash-heredoc backslash collapse struck twice more (`.meta/version`, INDEX log line): `\\v` became a
  vertical tab. Byte-level scripts written with Write fixed them; scan for bytes < 32 after any shell edit.
- `finditer(text, pos, endpos)`: `^` matches only at the real start, and `\b`/lookbehind see before `pos`, but
  `endpos` truncates, so `$`/lookahead treat the segment end as the end of the text. Documented, not "fixed".
- PowerPoint's `TextRange.Text` reports a soft line break as `\v`, so `Contains("a\vb")` verifies the break.
