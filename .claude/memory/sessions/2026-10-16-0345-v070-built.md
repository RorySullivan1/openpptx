## Gotchas & dead ends
- **Local `main` was stale** (`eed4232`, v0.5.1-era) while `origin/main` is `100a9c8`. The first "vs v0.6.0" benchmark
  silently compared against v0.5.1. Always `git fetch` and use `origin/main` as the baseline.
- **The Bash tool collapses `\\` to `\` inside heredocs**, so docstrings written via `python - <<'EOF'` got `"\v"`, `\1`,
  `\g` (a control char and an invalid escape). Use Edit/Write for anything with backslashes; `python -W error` compile
  of the touched files catches it (a cached .pyc hides SyntaxWarning on plain import).
- A string forward ref in a module-level alias (`Union[str, "re.Pattern[str]"]`) fails sphinx-autodoc-typehints in
  every importing module; `re.Pattern[str]` is subscriptable at runtime from 3.9, so no string is needed.
- The 3.11 interpreter has no deps; the work-count gate needs a throwaway venv (`lxml==6.1.3` to match the budget)
  plus `PYTHONPATH=src`.
- In a combined benchmark process, `medium` open read +11%; alone with warm-up it is flat. Same in-process ordering
  effect v0.6.0 recorded for `medium` iter1x.
- `TextMatch.runs` excludes empty runs inside a match; replace still removes them (they sit between first and last).
